# КП для SMILE LUX (TIZER, SOKOF)

Предварительное коммерческое предложение Cloudplus: приём заявок торговых точек из Telegram,
сборка накладной по прайсу и учёт расчётов с точками.

- Живая страница: https://abmarat11-art.github.io/demo-kp-smilelux/
- Один файл `index.html`, без сборки.
